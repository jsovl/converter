# Конвертер величин

Десктопное приложение на Python с графическим интерфейсом на `CustomTkinter`. Переводит значения между единицами измерения, температурными шкалами и системами счисления, хранит историю последних конвертаций и позволяет скопировать результат в буфер обмена.

## Основные возможности

* **Конвертация величин.** 20 категорий с линейными коэффициентами: время, давление, длина, заряд, масса, мощность, напряжение, объем, объем информации, площадь, проценты и доли, разрешение экрана, сила, сила тока, скорость, скорость передачи данных, сопротивление, углы, частота, энергия.
* **Температура.** Перевод между шкалами Цельсия, Фаренгейта и Кельвина с проверкой на абсолютный ноль.
* **Системы счисления.** Двоичная, троичная, четверичная, пятеричная, восьмеричная, десятичная и шестнадцатеричная. Поддерживаются отрицательные числа и три формата вывода: «Обычный», «С префиксом» (`0b`, `0o`, `0x`), «С группировкой разрядов».
* **Валидация ввода.** Принимается десятичная запятая и точка, а также экспоненциальная запись. Отклоняются нечисловой ввод, `inf` и `nan`, отрицательные значения (кроме температуры и углов), значения ниже абсолютного нуля, цифры, недопустимые для выбранной системы счисления, и результаты, не помещающиеся в число с плавающей точкой. Ошибки показываются в отдельном контрастном окне.
* **История.** Хранятся три последние уникальные конвертации. Повторная конвертация с теми же параметрами не создает дубликат, а поднимает запись наверх. Клик по записи восстанавливает категорию, единицы, значение и формат вывода.
* **Копирование результата.** Кнопка «Копировать» помещает результат в буфер обмена и на 1,5 секунды меняет подпись на «Скопировано».
* **Смена темы.** Переключатель между светлой и тёмной темой.

## Архитектура проекта

Проект разделен на два слоя:

|Файл|Назначение|
|-|-|
|`converter_logic.py`|Бизнес-логика: таблицы единиц, функции конвертации, классы категорий, валидация ввода, история конвертаций|
|`converter_ui.py`|Графический интерфейс: главное окно, выпадающие списки с прокруткой, окно ошибки, тема|
|`test_project.py`|Модульные тесты на `pytest` для `converter_logic.py`|

**Модуль `converter_logic.py` не зависит от GUI.** Он не импортирует `CustomTkinter` и может использоваться и тестироваться отдельно, без дисплея. Интерфейс только вызывает логику и показывает результат.

Каждая категория реализована отдельным классом с общим интерфейсом `Category` (паттерн «Стратегия»):

* `LinearCategory` — единицы, связанные коэффициентами;
* `TemperatureCategory` — температурные шкалы;
* `NumberSystemCategory` — системы счисления.

Функция `get_category(name)` возвращает нужную категорию по названию. Ошибки разделены на два типа: `InputError` (некорректный ввод) и `CalculationError` (сбой вычисления).

## Требования и установка

* Python 3.8 или новее (модуль `tkinter` входит в стандартную поставку Python);
* [`customtkinter`](https://github.com/TomSchimansky/CustomTkinter) — для интерфейса;
* [`pytest`](https://docs.pytest.org/) — для запуска тестов.

Установка зависимостей:

```bash
pip install customtkinter pytest
```

## Как запустить

Запускайте из папки проекта:

```bash
python converter_ui.py
```

## Как запустить тесты

```bash
pytest -v test_project.py
```

Тесты покрывают `converter_logic.py`: целостность данных, функции конвертации, категории, валидацию ввода (включая `inf`/`nan` и переполнение), системы счисления и историю. Графический интерфейс `converter_ui.py` не импортируется и не тестируется, поэтому дисплей не нужен.
